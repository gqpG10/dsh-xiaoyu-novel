# 读者视角评审（xiaoyu-reader-review）

审校清单挑「错」（逻辑硬伤、人设崩坏），这份评「好不好看」。核心方法：**放下作者全知**——你是第一次读到这一章的追更读者，不记得大纲、不知道谜底、只记得正文实际给过什么。

## 评审前准备

1. 只读正文，不读章纲与设定（作者真相会污染读者视角）；
2. 从上一章末尾接着读（衔接是否自然）；
3. 预设自己是手机上免费阅读的读者：耐心只有三段，随时可能划走。

## 四账评审

### 1. 期待感账目（最重要）

每章读完问三个问题：
- **本章建立了什么期待？**（新悬念、升级的冲突、被预约的事件——如「下周三他会来」）
- **本章兑现了什么？**（上一章的钩子是否在本章兑现、兑现得是否足量）
- **本章欠下了什么？**（抛出但未兑现的期待，记入期待债）

输出格式：
```
期待账：
  建立：fs-007 回收预告（读者已知「只作证」句要兑现）
  兑现：✓ 买主钱账给了答案（不退，加注）
  欠债：空手者为什么怕存量（+1 章未兑）、下周三之约（新债）
```

**期待债超过 3 条且连续 2 章不兑** → 判「读者疲劳风险」，建议下章必兑至少一条。

### 2. 节奏体感

- **划走点**：哪一段你想跳过？（超过 8 行没有新信息/新冲突的段落）
- **翻页点**：哪一句让你忍不住往下翻？（记下来——这是有效的钩子样本）
- **单章三段论**：开头 300 字有没有事？中段有没有一次情绪或信息转折？结尾钩子是哪种型（悬念/行动/情感/物件）？

### 3. 人物弧光感知

- 本章读者对主角的理解变化了什么？（没变化 = 平章，连续 3 章没变化 = 弧光停滞）
- 配角是否只干了「工具人」的活？（出场只为递一句话的配角记「扁平化风险」）

### 4. 伏笔记忆点

- 读者此刻记得几条活跃伏笔？（正文 5 章内未触达的伏笔，读者已忘——标「记忆冷却」）
- 本章是否泄露了「读者不该知道」的信息？（对照伏笔台账 reader_known 字段）

## 输出格式

```
# 读者评审 · v02-c075《只作证》

期待账：建立 1 / 兑现 2 / 欠债 3（明细……）
划走点：第 4-7 段（对白来回无新信息）
翻页点：「他没退钱，又买了一张」（前 300 字反着落地）
弧光：主角从「压制」到「接纳」站法定型 ✓
伏笔：fs-007/fs-009 兑现 ✓；fs-002 连续 15 章未触达（记忆冷却）

结论：本章体感 ★★★★☆——双回收足量，但期待债累积到 3 条，下章至少兑一条。
```

## 纪律

- 评审输出给作者决策，不直接改稿（改稿走审校清单或去 AI 味技能）；
- 期待账的「兑现」必须能在上一章正文里找到出处（不能凭大纲脑补）；
- 卷内复盘时，把每章期待账串成曲线：连续欠债的段落就是断更风险点。
