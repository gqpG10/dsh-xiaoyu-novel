# 去 AI 味（xiaoyu-qu-ai-wei）

## 0. 先纠正一个前提

AI 味不是"被检测出来的味道"。检测器读的是困惑度和句长方差；靠错别字、乱码、随机断句、同义替换、水词把分数刷下去，读者那边只会更假。本技能只做一件事：**把句子改回"有人在写"的状态**，所有判据都对着读者，不对着任何检测器。

真正被省掉的是三样东西：

- **具体**——读者能不能用手指到那个东西。"一股压迫感"指不到；"四百斤的铁门贴着后脖颈压下来"指得到。
- **不匀**——每句是不是一样重。AI 写出来像节拍器，人写出来像呼吸。
- **代价**——叙述者有没有冒风险。人敢写丑、写脏、写无关、写得不好听；AI 永远体面。

一句话判据：**把这段读给一个不认识作者的人听，他会不会问"这是人写的吗"。**

## 1. 五层病征（先定位，再动刀）

改稿最大的浪费是"从头到尾润一遍"。先定位病灶在哪一层，只改那一层。

| 层 | 症状 | 判据（当场能验） | 手术 |
|---|---|---|---|
| 词 | 套话、万能副词、模糊量词、抽象大词 | 把词删掉，句子意思毫发无损 | 换具体物象 |
| 句 | 等长、完整、主谓宾齐全、三项并列 | 连续 5 句字数差不到 8 字 | 拆短句、去对称 |
| 段 | 等长、段末点题、每段自足 | 段落能任意调换位置而阅读不受影响 | 造咬合 |
| 章 | 信息均匀、节奏匀速、每章结构雷同 | 读完三章能预测第四章 | 变速 |
| 叙事者 | 全知、无立场、无身体、无知识边界 | 叙述者知道所有人的想法，且从不疲惫、从不误判 | 收限知 |

**叙事者那一层最致命，也最少人改。** 词句改得再干净，只要叙述者还是"无所不知且永远正确"，读起来就是 AI。

## 2. 十二式手术

每式给一组对照。左=病灶，右=改后。改后不是唯一解，判据是右边那三样有没有回来。

**① 删解释**——把读者能自己推出来的因果明写出来，是替读者干活。
- ✗ 他之所以没有立刻回答，是因为他清楚，一旦开口，就等于承认了自己的失败。
- ✓ 他没答。答了，就是认了。

**② 断句**——AI 的句子永远完整、永远结束在句号。人说话会断。
- ✗ 他缓缓转过身，目光落在窗外那片被雨水打湿的树叶上，心中涌起一阵说不出的酸楚。
- ✓ 他转身。窗外那片叶子被雨钉在玻璃上，抖了一下，不动了。他喉咙发紧。

**③ 换具体**——抽象名词是在替读者总结感受，具体物件是把感受的活儿交回去。
- ✗ 房间里弥漫着一股压抑的气息。
- ✓ 屋里有隔夜烟味，混着没倒的泡面汤。窗帘拉了一半，光从缝里切进来，照见桌上一层灰。

**④ 换私人比喻**——通用比喻（像刀、像冰、像闪电）是所有人的，也是没有人的。
- ✗ 那声音像一把刀，刺进他的心脏。
- ✓ 那声音像他爸修自行车时链条崩开的那一下——先"铮"一声，然后什么都听不见了。

比喻的取材域必须来自这个人物的经历、职业、年龄。农民不会用"如同手术刀般精准"。

**⑤ 加闲笔**——与主线无关，但把"这个人会注意什么"一起交出来。
- ✗ （没有闲笔，每句都在推进剧情）
- ✓ 等电梯时他数了数地砖，十七块。有一块裂了，缝里嵌着半个烟头。

配比：每 800–1200 字一处。闲笔必须与人物状态同构（焦躁的人注意裂缝，饥饿的人注意烟头旁边的油渍），否则是注水。

**⑥ 情绪外化**——情绪词是结论，身体反应才是证据。
- ✗ 他很紧张。
- ✓ 表格填错了两回，第二回把出生年份写成了今年。笔尖在纸上戳出一个洞。

关键是**动作误差**：手抖导致扣子扣错、紧张导致说错称呼、害怕导致走错楼层。误差比"心跳加速"可信十倍。

**⑦ 对话加噪声**——真人对话不传递信息，传递关系。
- ✗ "你为什么要这么做？"他质问道。
- ✓ "你图什么。"
  "……"
  "我问你图什么。"
  "你先坐。"

噪声包括：答非所问、重复、沉默、打断、称呼变化、口头禅、方言词、说到一半改口。

**⑧ 打散对称**——三项并列是排比惯性，读起来像口号。
- ✗ 他冷静、果断、狠辣，像一把出鞘的刀。
- ✓ 他做事很干脆。就是有时候干脆得让人不舒服——上次他把人从三楼扔下去，扔完先去洗手。

**⑨ 收限知**——一段只待在一个脑袋里，只写他能感知的。
- ✗ 她不知道，此刻在门外，那个男人正握紧拳头，眼里满是挣扎。
- ✓ 门外有动静。她停下手里的活，听了一会儿，又没了。

**⑩ 段末去点题**——每段结尾都升华，读者就没有自己想的余地。
- ✗ ……他终于明白，有些路，注定要一个人走。
- ✓ ……他把伞收起来，抖了两下，靠在门边。

**⑪ 换句首切入口**——连续三句同一主语开头，就是模板推进。
- ✗ 他走进房间。他看到桌上有封信。他拿起信。
- ✓ 房间里一股旧纸味。桌上有封信，没封口。他抽出来，只有半张。

**⑫ 变速**——高潮处句长必须骤降，段落必须变短；匀速=无高潮。
- ✗ 他冲进火场，抱起孩子，冲出门口，整个过程只用了不到十秒。
- ✓ 他冲进去。火。孩子在地上，不动。他抱起，转身。门框塌了半边。他侧身挤出去，背上烫了一下，没回头。

## 3. 每千字配比表

改到什么程度算够，用数字卡，不靠感觉。脚本能直接测。

| 项 | 目标 | 说明 |
|---|---|---|
| 短句（≤8 字） | 80–250 字 / 千字 | 呼吸点，补在情绪落地处，不要均匀撒 |
| 长句（≥45 字） | 3–15% | 只在"拖着走"有必要时用（回忆、窒息、铺陈） |
| 句长变异系数 | ≥0.55 | 低于 0.45 = 节拍器 |
| 段落长度变异系数 | 0.6–1.2 | 连续 5 段等长 = 机器排布 |
| 套话 | ≤2 处 / 千字 | 见附录词表 |
| 万能副词（缓缓/轻轻/微微） | ≤8 处 / 千字 | 一个动作能自证速度就别加副词 |
| 模糊量词（一抹/一丝/一缕） | ≤6 处 / 千字 | 换成形状、尺寸、来源 |
| 抽象大词（气息/意志/压迫感） | ≤4 处 / 千字 | 换成可测的物理现象 |
| 三项并列 | ≤0.8 处 / 千字 | 留最狠的一项 |
| 解释插入（也就是说/这意味着） | ≤1 处 / 千字 | 删掉，让因果自己长 |
| 具体细节（数字/拟声/尺寸/价格） | ≥2 处 / 千字 | 可信度的唯一来源 |
| 感官类别 | ≥4 类 | 缺的通常是体感：胃、喉咙、指尖、耳鸣 |
| 对话占比 | 12–40% | 按体裁浮动，议论体可豁免 |
| 段末总结句 | ≤10% 的段落 | 其余段落停在动作或物件上 |

## 4. 写前必填：人物声音卡

去 AI 味最省力的办法不是改句子，是**让人物带着声音进场**。每个主要人物动笔前填六项，填不满就别写他的台词：

1. **口癖**：他重复哪个词、怎么起句、句尾落在哪（"你听我说""不是，你听我说"）。
2. **知识边界**：他不懂什么（这决定他会不会用错词、会不会问蠢问题）。
3. **比喻取材域**：他拿什么打比方（修车的、卖菜的、当兵的，取的喻体完全不同）。
4. **回避话题**：他绕开什么、被问到会怎么岔开。
5. **身体习惯**：紧张时手放哪、说谎时看哪、累了先揉哪。
6. **说话目的**：这段对话他想得到什么（要东西 / 要台阶 / 要对方先开口）。

六项齐了，台词自己就会带毛边；不齐，写出来必然是"两个 AI 在交换信息"。

## 5. 三轮修订（不要一遍改完）

**第一轮·粗修（结构层，只动不加）**
- 删掉所有段末点题句。
- 每 800 字标一处闲笔位置，先留空。
- 检查视角：每段标出"谁在感知"，出现两个脑袋就砍一个。
- 检查信息：把"读者能推出来的因果"全部划掉。

**第二轮·精修（句法层，逐句过）**
- 45 字以上长句：能拆就拆。
- 连续 5 句字数差小于 8：打断。
- 三项并列：砍成两项或一项。
- 每句问一次："这句话删了，读者会漏掉什么？"答不上来就删。
- 补具体：每 200 字至少一个能用手摸到的东西。

**第三轮·冷修（隔 12 小时以上）**
- 朗读。读不顺的地方就是 AI 味残留。
- 只改三处：最假的一句、最满的一段、最像总结的结尾。
- 交给一个没看过前文的人读 300 字，问他"这人想干什么"——答不出=信息没落地；答得太全=没有闲笔。

## 5.5 落盘纪律（edit 硬线）

改稿最后一步是把改动写回文件。`edit` 工具只认「真改动」：`old_string` 与 `new_string` 逐字相同会被直接拒绝（`old_string and new_string must differ`），一次白烧一步、还容易越急越乱。

- **只发改过的段落**：通读时记下问题点，改哪段发哪段。没改的段落不要为了「整段替换」再发一遍——它本来就是原文。
- **发之前自比**：把要写的 `new_string` 跟 `old_string` 对一眼，一样就跳过。只差空白、标点、全半角也算一样。
- **报 must differ 就是「这段没病」**：跳过它发下一段，禁止加一个字凑数、禁止原样重试。只有 `old_string` 找不到（失配）才重读该段再改。
- **整章一处都没改**：回报「本章已达标，保留原文」+ 2-3 个可选润色点，不要硬改出 AI 味。
- **合并发送**：相邻段落一次 `edit` 带走（`old_string` 带上下文），同一文件连续 edit 控制在 3 次以内，到上限把剩余问题写进回报。

## 6. 禁术清单（这些只会更假）

| 做法 | 为什么更假 |
|---|---|
| 加错别字、乱码、随机删字 | 读者读到的是"不认真"，不是"人味" |
| 同义词替换（看→凝视，说→道） | 更书面、更均匀，AI 味反而加重 |
| 灌语气词（啊/呢/吧/嘛）刷频率 | 均匀分布的语气词是最明显的机器特征 |
| 随机断句、去标点 | 破坏的是可读性，不是 AI 味 |
| 加脏话、加性描写当"人味" | 脏话要有人物动机才成立，否则是贴上去的 |
| 加"说实话""讲真"式翻译腔 | 另一种模板 |
| 注水拉长（加形容词、加环境描写） | 水词是 AI 味的主要来源之一 |
| 让叙述者跳出来说"这只是个故事" | 元叙述是遮羞布，不是人味 |

判断标准只有一条：**这个改动，是让读者更信，还是更不信。**

## 7. 量化闸门

脚本只诊断、不改写；不要让它自动改，自动改出来的东西比原稿更假。

    python3 <技能目录>/scripts/aiwei_scan.py 草稿.txt                  # 分层体检
    python3 <技能目录>/scripts/aiwei_scan.py 草稿.txt --top 20         # 列出最像模板的 20 句
    python3 <技能目录>/scripts/aiwei_scan.py 草稿.txt --json           # 机器可读，接工作流
    python3 <技能目录>/scripts/aiwei_scan.py 草稿.txt --gate 78        # 低于 78 退出码 1，退回重写
    python3 <技能目录>/scripts/aiwei_scan.py 草稿.txt --compare 参考段落.txt   # 与人类样本逐项对照
    python3 <技能目录>/scripts/aiwei_scan.py 草稿.txt --detector         # 检测器视角（句长突变/连接词/四字格/口语度）

**读分方法**
- ≥85：可发，剩下的靠冷修。
- 70–84：不改整体，只修报告里"首要病灶"那两三项。
- <70：回炉，别在句子上磨，先补具体和闲笔。
- 出现"硬伤维度"（任一单项 ≤22）：总评已被封顶，先修那一项，别管别的。

**最有用的三个数**：句长变异系数、套话密度、具体细节密度。前两个决定"像不像机器"，第三个决定"像不像真的"。

## 8. 验收五测

1. **朗读**：出声读 300 字，换气点是不是均匀得像节拍器。
2. **遮盖**：遮住每段头三个字，还能不能猜出这段要干什么——猜得出=太规整。
3. **打乱**：调换任意两段，读起来"卡"不"卡"——不卡=段落自足，缺咬合。
4. **复述**：让别人一句话复述，若能复述出全部信息=没有闲笔，密度过高。
5. **五问**（针对任意一段）：谁在感知？他此刻身体什么状态？他知道什么、不知道什么？哪句话他绝不会说？哪个细节只有他会注意到？

五问答不出三问以上，这段就得重写，不是润色。

## 9. 体裁微调

- **网文**：短句占比可到 30–40%，长句压到 3–8%，节奏优先；套话照样全删，尤其"冷笑一声""嘴角勾起"。
- **严肃文学**：长句可到 20%，但每段必须有一次呼吸（一个短句或一次断行），否则读起来是译文。
- **悬疑**：感官向听觉与体感倾斜，视觉降到 40% 以下；信息差靠"叙述者不知道"，不靠"作者不说"。
- **言情**：情绪外化优先，禁用"心中一动""心头一暖"；亲密场景的具体度要高于日常场景，否则是说明书。

## 10. 快速版（只有五分钟）

按顺序动五刀，能拉回大半：

1. 删掉所有段末"他终于明白/他知道/这一刻"开头的句子。
2. 每段找一句 40 字以上的，拆成三句。
3. 找三处"心里/眼中/气息"，换成一次身体反应。
4. 找一段对话，删掉所有"他说道""淡淡地"，只留引号和动作。
5. 结尾的升华句删掉，换成一个动作或一个物件。


## 11. 检测器视角（朱雀一类）

### 原理：它不是关键词黑名单

朱雀这类检测器是**分类器**：喂进去的是文本的统计特征，输出一个概率。它不看"你写了什么词"，看"这段文字有多可预测"。

已知被大量使用的特征，大致五类：

- **困惑度（perplexity）**：给定上文，下一个词多容易被猜中。AI 文本更可预测，人类更跳。
- **句长突变度（burstiness）**：句长忽长忽短的程度。人写的东西起伏大，AI 趋近匀速。
- **虚词与连接词分布**：然而/因此/此外/不仅 这类书面连接词，AI 用得更多更匀。
- **词汇与成语密度**：四字格连发、成语堆叠，是训练的默认文风。
- **标点与段落节奏**：只用逗号句号、段落等长，是"机器排版"的指纹。

结论很直接：**没有"本地一定能过"的方法**。检测器版本在迭代，同一篇稿子在不同版本上结果都可能不同。能做的只有一件事——把上面这几类特征推回人写的分布里。这也正是本技能前面十二式在做的事，检测器只是从另一个角度给证据。

### 别做的事（都会反噬）

零宽字符、错别字、乱码、随机删字、同义替换、硬塞语气词。这些手段检测器侧早已收录为特征，人工读起来更假——等于用两个问题换一个。

### 量法

    python3 <技能目录>/scripts/aiwei_scan.py 草稿.txt --detector

输出「检测器视角」八项 + 人写度。门槛按章节正文卡：

| 特征 | 目标 | 改法 |
|---|---|---|
| 人写度 | ≥80 | 低于 80 按最弱的三项改 |
| 句长突变度 | ≥0.55 | 每 5-7 句插一个 3-6 字短句；长句拆成动作串 |
| 连接词密度 | ≤6/千字 | 删掉一半"然而/因此/不仅"，让因果自己连 |
| 四字格密度 | ≤1.5/千字 | 成语换成大白话动作，一章留一两个点睛 |
| 口语标记 | ≥5/千字 | 对话与心声里自然出现呢/吧/咋/啥/愣/回头 |
| 标点种类 | ≥6 | 补 …… —— ？ ！ （） 与破折号停顿 |
| 虚词密度（的/地） | ≤6/百字 | "他的那把生锈的刀"→"他那把锈刀" |
| 短段比例 | ≥10% | 一句一段做呼吸，别全是大段 |
| 句首多样度 | ≥50% | 连续同字开头就换切入口 |

### 实测参照

同一段料的两种处理：AI 味原稿人写度 71、按本技能重写后 92。差距主要来自句长突变度（0.55→0.77）、口语标记（0→6.2/千字）、短段比例（0→36%）。

**读法**：人写度是相对指标，不是通过证书。它到 85 以上、且正文念着顺，才是这段文字真正写好了；检测器过不过，是它的判断，不是本技能的承诺。
