# 改写案例集（rewrite-playbook）

只讲一件事：同样的情节，怎么从"AI 写的"改成"人写的"。
每例都给原稿、病灶、手术记录、成品，以及**改坏的版本**——后者比原稿更值得看。

---

## 案例一 · 开篇 500 字（全流程）

### 原稿

> 夜色如墨，浓稠得仿佛化不开。林尘缓缓睁开双眼，一股难以言喻的力量在他体内缓缓涌动，如同沉睡已久的巨兽苏醒。他深吸一口气，缓缓站起身，眼神中闪过一丝不易察觉的坚定。
>
> 空气中弥漫着一股淡淡的血腥味，他不禁皱了皱眉。就在这时，门外传来一阵急促的脚步声，紧接着，房门被猛地推开。一个身着黑衣的男子站在那里，目光深邃，嘴角勾起一抹冷笑。
>
> "你终于醒了。"男子淡淡地说道，语气中带着一丝不容置疑的威严。
>
> 林尘沉默着，没有说话。他知道，眼前这个人并不简单。然而，他更清楚的是，自己已经不是三天前那个任人宰割的少年了。
>
> "你是什么人？"林尘缓缓开口，声音沙哑。
>
> 时间仿佛在这一刻静止了。他隐隐觉得，这个人的出现，将会彻底改变他的命运。

### 扫描诊断

    人味指数 46.0 / 100   风险等级：高
    硬伤维度：套话密度（76 处/千字）、副词密度（28 处/千字）
    首要病灶：套话密度 / 副词密度 / 模糊量词 / 具体细节 0 处
    句长变异系数 0.48（低于 0.55，"节拍器"）
    段落长度变异系数 0.37（八段几乎等长）

一句话：**每个词都在替读者总结，没有一件能用手摸到的东西。**

### 手术记录

| 原句 | 病灶 | 改法 | 改后 |
|---|---|---|---|
| 夜色如墨，浓稠得仿佛化不开 | 比喻是通用库存，无信息 | 换成本场景独有的视听 | 门是被踹开的 |
| 一股难以言喻的力量缓缓涌动 | 抽象大词 + 副词 + 模糊量词，三连 | 全部删除，改为可观测 | 先听见鞋跟磕门槛，金属磕水泥 |
| 空气中弥漫着血腥味 | 环境套话模板 | 加来源和混杂气味 | 血腥气混着雨，还有股劣质旱烟 |
| 目光深邃，嘴角勾起一抹冷笑 | 表情套话双拼 | 换成身体细节 | 湿头发贴额角，伞骨断了一根 |
| "你终于醒了。"男子淡淡地说道 | 副词 + 解释语气 | 砍到两个字 | "醒了？" |
| 他知道，眼前这个人并不简单 | 替读者下结论 | 改为不答 | 林尘没答 |
| 时间仿佛在这一刻静止 | 环境套话 | 用一个物理动作替代 | 掌心压在木板上，底下有颗钉子尖 |
| 将会彻底改变他的命运 | 抽象预告 | 落到一个具体物件 | 半块饼，裂缝里落进一点灰 |

### 成品

> 门是被踹开的。
>
> 林尘先听见鞋跟磕在门槛上，金属磕水泥，一下，不响。然后才闻到味儿——血腥气混着雨，还有股劣质旱烟。
>
> 来的人不高，湿头发贴在额角，手里拎着把伞，伞骨断了一根，另一根翘着。他进门前把伞靠在门框上，靠歪了，滑下来，他也没扶。
>
> "醒了？"
>
> 林尘没答。他撑着床沿坐起来，掌心压在木板上，硌得慌——底下有颗钉子尖露出来，昨天他就发现了。
>
> "三天。"那人竖起三根手指，指甲缝里全是黑的，"你睡了三天。"
>
> 林尘嗓子干，咽了口唾沫，像吞了把沙子。
>
> "你是谁？"
>
> 那人笑了一下，不是好笑的。他从兜里摸出个纸包，抖开，半块干硬的饼，搁在桌上，推过来。
>
> "先吃。吃完再说。"
>
> 窗外的雨小了，滴答，滴答，砸在台阶上。林尘盯着那半块饼，没动。饼上有一道裂口，裂缝里落进去一点灰。

### 复核

    人味指数 94.4 / 100   风险等级：低
    短句占比 27.8%   句长变异系数 0.59   具体细节 6.2 处/千字

**关键不是句子变短了，是每一句都多了一个"只有这个场景才有"的物件**：断伞骨、指甲缝、钉子尖、饼上的灰。AI 稿里没有任何一件东西是"存在过的"。

## 案例二 · 情绪场景（诊断式改写）

原稿（典型 AI 处理）：

> 她坐在窗前，看着外面的雨，心中涌起一阵难以言喻的悲伤。泪水在眼眶里打转，她终于忍不住，低声哭泣起来。她想起了他们曾经一起走过的那些日子，那些美好的回忆如同潮水般涌来，让她几乎无法呼吸。

三个病灶：情绪贴标签（悲伤/忍不住）、比喻库存（如同潮水）、全知回溯（想起了……那些日子）。

改后：

> 她坐在窗边，手里捏着个杯子，水早凉了。
>
> 楼下有人在收晾在外面的被子，拍得"嘭嘭"响。她听着，忽然把杯子放回桌上，放得有点重，水晃出来一点，顺着杯底流到桌面上。
>
> 她没擦。

**为什么成立**：悲伤没有一个字被说出来，但"水凉了没喝""放杯子放重了""没擦"三件事连起来，读者自己会得出那个结论——而且是他自己得出的，所以他信。

## 案例三 · 对话场景

原稿：

> "你到底想怎么样？"李明愤怒地问道。
> "我不想怎么样，"王强冷冷地回答，"我只是想拿回属于我的东西。"
> "那些东西本来就不是你的！"李明大声说道。
> "是吗？"王强嘴角勾起一抹讥讽的笑容，"那你告诉我，它们是谁的？"

病灶：每句都完整、都带情绪副词、都精确回应上一句——这是"辩论"，不是"对话"。真人说话会跑偏、会答非所问、会突然沉默。

改后：

> "你到底想怎么样。"
>
> 王强没接。他把烟按在窗台上，按了两下才灭。
>
> "那些东西本来就不是你的。"
>
> "嗯。"
>
> "你嗯什么？"
>
> "我说，嗯。"他抬起头，"你刚才问我什么来着。"

**为什么成立**：三个噪声——不答、只回一个"嗯"、忘了问题。这三样在 AI 稿里永远不会出现，因为 AI 默认对话的功能是传递信息。真人对话的功能是试探和拖延。

## 改坏的三种版本（对照看）

同一段原稿："他走进房间，看见桌上有一封信，心中一紧，知道事情不妙。"

**① 机械去 AI（同义词替换 + 拆句）**

> 他步入房间，瞥见桌上搁着一封信，心头一凛，知晓事态不妙。

更假。书面语更重，均匀度更高，套话一个没少。

**② 造噪声（错别字 + 语气词）**

> 他走进房间，看见桌上有一封信啊，心中一紧呢，知道事情不妙了吧。

最假。读者读到的是"作者不认真"，不是"人写的"。

**③ 正确改法（具体 + 限知 + 动作误差）**

> 房间里有股旧纸味。
>
> 桌上有封信，没封口。他抽出来，只有半张。另外半张的撕口是新的，纸毛还立着。
>
> 他把信塞回去，塞了两次才塞正。

**为什么成立**：信的内容一个字没写，但"撕口是新的""塞了两次"已经把"事情不妙"和"他慌了"同时交出去——读者自己拼出来的结论，比被告知的结论牢。

## 附录 · 替换词表

左边是 AI 的默认选项，右边是至少三个具体方向。不是照抄，是提醒自己"还有别的可能"。

| 套话 | 可替换方向 |
|---|---|
| 空气中弥漫着…… | 气味来源 + 混杂物 + 留了多久 |
| 时间仿佛静止 | 一个具体的、慢下来的动作（表针、水滴、烟灰） |
| 嘴角勾起一抹冷笑 | 面部某块肌肉的具体变化，或干脆不给表情，只给动作 |
| 眼神中闪过一丝…… | 眼睛在看什么、看多久、有没有眨眼 |
| 深吸一口气 | 胸口的具体感受，或者别写，直接说话 |
| 心中一紧 | 身体哪一处紧了（胃、喉咙、后颈、指尖） |
| 不由自主地 | 直接写那个动作，删掉"不由自主" |
| 说不清道不明的…… | 说清一样，剩下一样不说 |
| 仿佛整个世界都安静了 | 具体哪个声音停了（空调、钟、邻居的电视） |
| 他知道，事情并不简单 | 他知道的那一件具体的事 |
| 一股暖流涌上心头 | 温度、位置、持续时间，或一个生理反应 |
| 令人窒息 | 呼吸的具体困难（吸到一半、喉咙发紧、必须张嘴） |
| 命运的齿轮开始转动 | 删。换成一件第二天就会发生的小事 |

## 最后一条

改完自查一句：**这段里，有没有一件东西是"只可能出现在这个场景里"的？**

没有，就还是 AI 稿，只是变短了。
