# 拆书与文风蒸馏（xiaoyu-teardown）

## 用途与边界

拆参考小说，产出**仿写约束**——结构层面学什么、文风层面学什么、什么是那本书的独有指纹（学了反而假）。参考小说只进拆解结果，绝不混进正文。

## 拆解流程（四步）

### 第一步：通读采样

- 全本扫一遍 frontmatter/章名/字数分布；
- 精读三类样本各 3 章：开篇 3 章（钩子与入戏）、高潮 3 章（情绪峰值技法）、最近 3 章（稳定期笔法）；
- 记录：每章 CJK 字数、对话行占比、单句长度分布。

### 第二步：结构拆解

对每个采样章回答：
- **本章职能**：推进主线 / 兑现期待 / 埋设 / 蓄力 / 过场？（用 beat-pacing 的拍型词汇）
- **钩子型**：结尾用的是悬念 / 行动 / 情感 / 物件哪型？
- **压放配比**：本章压抑与释放的大致比例（目测 ±10%）
- **信息释放纪律**：本章给了几个新信息？有没有一次给太多？

产出「结构指纹」：该书多少章一个小高潮、多少章换地图、钩子型的轮换规律。

### 第三步：文风蒸馏

量化五项（对照文本算，不凭印象）：

| 维度 | 怎么量 | 产出约束示例 |
|---|---|---|
| 句长 | 平均句长 + 超过 40 字的句子占比 | 平均 18 字，长句 <10% |
| 对话密度 | 对话行 / 总行数 | 45%（市井流高，仙侠低） |
| 标点习惯 | 逗号密度、破折号/省略号频率 | 省略号近乎为零，破折号每章 ≤2 |
| 段落节奏 | 单句成段占比、最长段行数 | 单句成段 15%，最长段 ≤5 行 |
| 口头禅 | 高频专属短语（≥5 次） | 「……的说」禁用（那是他家指纹） |

### 第四步：仿写约束成文

输出一份可直接贴给写手的约束单：
```
# 仿写约束 · 源《XX》
结构：20 章一小高潮，钩子型两章一换；压放比 4:6；每章新信息 8±2 项
文风：平均句长 18 字；对话 45%；单句成段 15%；最长段 5 行
禁用：源书口头禅「……」、专属比喻「……」（指纹不学）
不学：其金色开篇（我书已有自己的黄金三章）
```

## 纪律

- **指纹不学**：源书最强个人标记（口头禅/独家比喻/人物名梗）写进禁用清单；
- **结构优先于文风**：先学节奏与信息纪律（可迁移），文风只取量化参数（句长/密度）；
- **一次只拆一本**：同时仿两家必然串味；换源前先出「卸载清单」（上一本的哪些约束要停用）；
- 拆解结果存 novel/teardown/<书名>.md，写手提示词引用它而不是引用原文。
